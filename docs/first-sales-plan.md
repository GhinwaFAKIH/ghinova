# GHINOVA: first-sales plan

Focus offer: the existing €5 PDF chatbot workshop. This is an experiment to establish demand, not a revenue forecast. No advertising spend is needed for this plan.

## Before promoting

Open the existing Whop checkout as a visitor. Verify product name, €5 base price, any tax, one-time billing, availability and refund terms. Verify the notebook, sample PDF and workbook are accessible to purchasers using Whop's preview/test facilities where available. Do not make a charge just to test. Checkout and post-payment delivery were not verified during this website update.

## Seven-day launch

1. Verify the checkout and delivery. Open the new landing page on your phone.
2. Publish the LinkedIn post below with a screenshot of an actual notebook result; do not use a fabricated result.
3. Record a 30–45 second screen demo: question, retrieved passage, page citation, unsupported question. Show only sample documents.
4. Share the demo on GhinAI Bites. Put the workshop link in the profile; use a Story link where available.
5. Answer a relevant learner question in a Python/AI community. Include the free tutorial only when the community permits promotion. Avoid unsolicited mass messages.
6. Share one useful lesson: keyword overlap does not prove a passage answers a question. Link to the free tutorial.
7. Record Whop product views, orders and refunds if available. If visits are low, improve distribution. If views arrive without orders, inspect checkout, positioning, sample quality and visitor feedback before creating another product.
