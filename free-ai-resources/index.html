Where should beginners start?

If you are new to AI, begin with Introduction to AI and Python for AI Beginners. Then try the NLP workbook before moving on to RAG, knowledge graphs or agents.

For a step-by-step project, read the Python PDF chatbot tutorial. For personalized lessons, explore online AI training.

Frequently asked questions

Are these resources really free?

Yes. The five starter workbooks are available without payment. Some separate GHINOVA workshops and courses are paid.

Do I need an API key?

No API key is required for the examples in these starter workbooks. Some examples require Python packages installed locally.

Can I use them without knowing Python?

Start with the introduction and Python beginner lessons first. The RAG and graph workbooks are easier once you know basic Python.
